Avengers Memory Game

A fun, interactive memory matching game built with HTML, CSS, and JavaScript, featuring your favorite Avengers heroes.
The goal: Match all the hero pairs before time runs out and save the Earth!

🎮 How to Play

Click on a card to flip it and reveal a hero.

Flip another card to find its match.

If both cards match, they stay flipped.

Match all pairs before the timer ends to win!

You can replay the game using the “Play Again” button after finishing.

🧠 Features

Fully responsive — works on mobile, tablet, and desktop

Smooth flip animations using CSS transitions

Countdown timer with visual time display

Simple, colorful, and Avengers-themed UI

Lightweight and pure HTML/CSS/JS — no libraries required

🛠️ Tech Stack
Technology	Purpose
HTML5	Structure of the game
CSS3	Styling and responsiveness
JavaScript (ES6)	Game logic and timer

🚀 How to Run

Download or clone this repository:

git clone https://github.com/Pushpa2708/save-the-earth-game.git


Open the project folder:

cd avengers-memory-game


Run the game by opening index.html in your browser.

📱 Responsive Design

Desktop: 4 cards per row

Tablet: 3 cards per row

Mobile: 2 cards per row
Uses CSS flexbox and aspect-ratio for perfect scaling on all devices.
